# Troubleshooting

## TV not detected

- Confirm HDMI cable and TV input source.
- Run diagnostics and apply repair action.

## Controller duplicate input

- Verify HidHide is configured.
- Restart DS4Windows and re-run controller setup step.

## Playnite launch issues

- Verify Playnite installation path in profile.
- Re-run setup wizard Playnite step.
